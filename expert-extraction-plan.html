摸底方案

专家思维提取 · 如何科学判断哪些能力值得投入

核心观点

摸底 = 给通用大模型做诊断。
诊断两件事：不会的地方在哪，会但不稳的地方在哪。
诊断数据就是 baseline。

不靠主观判断排优先级——用数据证明哪些模块需要提取、提取后价值多大。

两个假设，两种证明

假设 A

通用大模型不会

专家知识是私有的、模型训练数据里没有，从根本上缺这个能力。

怎么证明

在决策树的关键判断节点做截断测试——把真实对话上下文给模型，问"下一步怎么做"，看行动方向对不对。

判定：行动方向与专家实际做法不同 = 不会。

假设 B

通用大模型会，但不稳定

训练数据里吃过专家的书/视频/公开内容，"知道"答案，但无法稳定执行决策路径。

怎么证明

同一个截断节点，跑多次（temperature > 0），看每次的行动方向是否一致。

判定：多次结果不一致 = 会但不稳。

↓

两个证明跑完 = baseline

每个模块、每个节点都有数据：对不对 × 稳不稳。
提取完成后再跑一遍同样的测试，对比即可证明提取价值。

执行方案
1

全量转文本

所有素材（视频/书/访谈/PPT）统一转为文本语料库，标注来源和位置。

2

主题聚类 → 能力模块归纳

AI 将全部素材聚类为话题，再归纳为 15-20 个能力模块。专家确认划分和产品范围。

3

自动提取决策树骨架

从素材中自动提取每个模块的决策路径，生成决策树初稿。

Case：某睡眠专家 ·「入睡困难」模块的决策树提取

假设专家有 80 个短视频、2 本书、6 段直播连麦涉及「入睡困难」话题

从 Step 2 聚类后，「入睡困难的分层干预」被归为一个能力模块

1提取节点

AI 扫描该模块所有素材，提取专家反复出现的判断和行动：

判断先区分躺下后多久睡不着——30分钟以内不算入睡困难，不要过度干预
判断入睡困难但白天不困 → 可能是睡眠时间需求本身就少，不是失眠
判断躺下脑子停不下来 vs 身体躺不住——两个方向完全不同
行动脑子停不下来 → 先确认是焦虑反刍还是兴奋联想，干预手段不同
行动焦虑反刍 → 认知搁置技术（写下来明天再想），不用呼吸法
行动兴奋联想 → 单调刺激法（数数/听白噪音），不用认知干预
红线持续 3 个月 + 伴随情绪低落/体重变化 → 必须排除抑郁，不继续给睡眠建议
红线正在服用安眠药想要减药 → 不给任何减药建议，转专科

2语义聚类

连麦里说"你躺下脑子转不转"、视频里说"想事儿的和不想事儿的完全是两回事"、书里写"需区分认知型与躯体型入睡障碍"
→ 合并为一个标准节点：「脑子停不下来 vs 身体躺不住」

3生成决策树

所有路径叠加后生成：

用户说"躺下睡不着" ├─ 多久睡不着？ │ ├─ <30min → 不算入睡困难，做预期管理 │ └─ >30min → 继续 │ ├─ 白天困不困？ │ │ ├─ 不困 → 可能是短睡眠者，调整预期 │ │ └─ 困 → 确认入睡困难，继续分型 │ │ ├─ 脑子停不下来 │ │ │ ├─ 焦虑反刍（担心/后悔/怕）→ 认知搁置 │ │ │ └─ 兴奋联想（计划/回忆/脑洞）→ 单调刺激 │ │ └─ 身体躺不住（翻来覆去/腿不安）→ 躯体评估 │ └─ 持续 >3月 + 情绪变化 → ⚠️ 排除抑郁，转介

这棵树由 4 段连麦 + 1 本书综合提取，核心分支在 5 条素材中反复出现。

决策树用于下一步的诊断测试，同时也是后续挖掘阶段的初稿。

4

在决策树上做诊断

在决策树的每个分叉节点，分别证明两个假设：

证明假设 A

截断测试 · 对不对

把到达该节点的上下文给模型，问"下一步怎么做"，跟专家实际做法对比。

行动方向不同 = 不会

证明假设 B

一致性测试 · 稳不稳

同一节点跑 N 次（temperature > 0），看每次结果是否一致。

结果不一致 = 会但不稳

Case：在「入睡困难」决策树上跑诊断

测试节点：「脑子停不下来」→ 焦虑反刍 vs 兴奋联想

这是该专家的私有判断——通用指南里不区分这两类，统一建议"放松训练"

A截断测试：对不对

给模型以下上下文，遮住专家后续做法：

用户：我每天晚上躺下至少一个小时睡不着
专家：白天会困吗？
用户：困，上班都打瞌睡
专家：躺下的时候是脑子停不下来，还是身体翻来覆去？
用户：脑子停不下来，一直在想事情

→ 模型，你下一步会怎么做？

专家实际做法：追问"想的是什么类型的事——是担心明天的工作，还是脑子里冒出各种乱七八糟的想法？"以此区分焦虑反刍和兴奋联想，给不同干预。

模型回答：直接给了"4-7-8 呼吸法 + 睡前不看手机"。

→ 判定：❌ 不会。跳过了关键分型，直接给通用方案。

B一致性测试：稳不稳

同一截断点跑 5 次：

第 1 次：直接给呼吸法  ❌

第 2 次：追问"想什么事"  ✅ 但没有区分焦虑/兴奋

第 3 次：建议写睡眠日记  ❌

第 4 次：直接给认知行为疗法介绍  ❌

第 5 次：追问"想什么事"  ✅ 但没有区分焦虑/兴奋

→ 判定：⚠️ 不稳定。5 次中 2 次追问了但追问方向不对，3 次直接跳过。路径未固化。

✓结论

这个节点同时命中两个假设：模型不知道要区分焦虑反刍和兴奋联想（假设A），即使偶尔追问了也不知道区分后该给不同方案（假设B）。标记为高优先提取节点。

截断点不需要人工选——Step 3 的决策树已找到所有分叉节点，直接在这些节点上跑测试。

5

输出优先级 + baseline

每个模块、每个节点的诊断数据汇总，按「不会」和「不稳」两个维度交叉排优先级。

差距小（大多做对且稳定）
差距大（做错或不稳定）
复杂度高
中优先级
当前能做但复杂度高，不稳定风险大
最高优先级
又难又做不好，提取价值最大
复杂度低
最低优先级
简单且做得到
中优先级
简单但做不好，可能 prompt 能修

Baseline 数据的价值

1排优先级——数据驱动决定先提取哪个模块
2证明价值——提取完成后跑同样测试，对比提升幅度
3定位节点——精确到每个判断节点的差距，挖掘目标明确
4持续监控——模型迭代后重跑测试，判断是否需要更新

摸底交付物

📋能力模块清单（专家确认版）
🌳决策树初稿（直接进入挖掘）
📊每个节点的诊断数据（对不对 × 稳不稳）
🎯优先级排序 + baseline
